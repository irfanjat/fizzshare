How it works

What is FizzShare?

FizzShare is a peer-to-peer file sharing service built for a Computer Networks term project. Your files travel over WebRTC — SCTP/DTLS/ICE — straight from one device to the other. We store nothing online: simply close your browser to stop sending.

Hostile origin: this page is not served over HTTPS, so WebRTC is disabled. Ask the host for the secure link.

📦

Shared straight from your device

WebRTC finds the shortest path between sender and receiver — sometimes your data never even leaves the building.

📏

No more file size limits

Because we never store the data, there's nothing to limit. Share files of any size, mindful of your own data usage.

🔒

Only the receiver can read it

DTLS-encrypted end to end, plus a per-file SHA-256 checksum both sides verify after every transfer.
